>> Chosen Topic -> Text-based RPG
| This project is a game relying on limited user
| input (choosing from pre-set options), and randomly
| generated values as a base for everything else. The
| code is written in a way that allows for relatively
| easy addition of new character classes, enemy types,
| and encounters.
[+]The gameplay loop is based on 'recruiting' characters
to the party, and then either going through randomly
chosen encounters, or making two characters duel each
other.
[↑]Progression and difficulty are based on the average
party level, with characters gaining them after each
won fight. Higher levels unlock new events, more types
of enemies, and new attacks for characters.
[★]The game has a system for saving and loading
progress, with the player specifying the name of the
'.txt' file they want to create with data of this run,
and loading previous ones by calling that name.


☰☰☰☰☰☰☰☰☰☰☰☰ RUN INSTRUCTIONS ☰☰☰☰☰☰☰☰☰☰☰☰
1 - Download and extract the files from the folder:
     > 'Main.py'
     > 'Character.py'
     > 'Enemy.py'
     > 'Attacks.py'
     > 'RandomEvents.py'
[!!!]Make sure all of the extracted files are located
in the same folder!
2 - To start the program, run the 'Main.py' file
3 - From the moment the program starts, all user input
    is inside a controlled system of either integer,
    or single-word answers
4 - To proceed, follow the instructions on-screen
